# Desktop source

- `src/` contains the React interface for devices, conversation, components and network settings.
- `src-tauri/` contains the Tauri application, native device and Agent integrations, and the background bridge.
- `builtin-clawpkgs/`, `optional-clawpkgs/` and `skills/petui/` contain public component inputs and authoring guidance.
- `scripts/` and `tests/` contain build tooling and verification.

See the [desktop build guide](README.md) for dependencies, platform setup and release configuration.

Agent Bus and hook endpoints use per-start owner-private capabilities (`bridge-runtime/client.json` and `hook.json`). Native `bridge_capability.rs` restricts the frontend to fixed local operations. Hooks load the current epoch at request time; see `src-tauri/bridge/packages/agent-session-bus/README.md` for external-client migration.

Cursor working state is published from the hook endpoint even when Claude hook sync is off. A failed Cursor tool stays in the same working turn, so it does not freeze the device on 执行失败. Device state also includes other local Agents while voice follow stays on the selected Agent. Codex discovery follows the live data directory, including TCodex at `~/.tcodex`. Device session cards include other local Agents' recent conversations, and voice routing stays on the selected Agent. Reconnecting USB no longer clears those local Agents as disabled.
